Date: 2026-09-19. Spec: `notes/20260919-kim-spectral-landing-design.md` (flow
sketch, decisions and ledger there). Source of every byte that lands:
`notes/probes/2026-09-19-kim-spectral-landing/` after fix pass 3. Audits:
three rounds by independent Opus auditors (round 3: one blocking sentence);
fix pass 3 was read line by line by the main session, which found comment
edits and one proof respelled `exact: erefl`.

in dependency order. The invariant is that every production file outside the
landing's list is unchanged, and that the five recompiled-only files are
unchanged as text.
Monad: no such structure; a linear order of copies and compiles, each
depending on the `.vo` files before it.
DSL: none needed; nothing composes except through the compiler's own
dependency order, which the step list states.

## Steps

0. Wait until no agent is compiling against the production manifest. The
   landing rewrites `manifest/pgg_analysis_manifest.vo`, after which every
   probe `.vo` built against the old one is inconsistent until rebuilt.
1. Staging, by a rocq-prover subagent: a directory `staged/` in the probe
   holding the six permanent-form files. Check, by script: each staged file
   equals its probe copy outside `Require` sentences; each staged import block
   equals the block `STATUS.md` spells, or production's block where it says
   "restored"; no staged file mentions `kim_landing_probe`.
2. `_CoqProject`: `lib/var_dist_supp.v` after `lib/mutual_info_recoding.v`;
   `instances/kim2025/five_card_mixing.v` before
   `instances/kim2025/five_card_analysis.v`.
3. Copy and compile alone, in this order, stopping at the first failure:
   `lib/var_dist_supp.v`, `instances/kim2025/five_card_mixing.v`,
   `instances/kim2025/five_card_analysis.v`,
   `manifest/pgg_analysis_manifest.v`, `manifest/pgg_tableau.v` (compile only),
   `manifest/pgg_tableau_syntax.v` (compile only),
   `manifest/pgg_analysis_client.v`, `instances/s5/s5_rows.v` (compile only),
   `instances/pgl27/pgl27_rows.v` (compile only),
   `instances/psl211/psl211_rows.v` (compile only),
   `instances/psl211/psl211_spectral_constancy.v` (compile only),
   `instances/kim2025/five_card_rows.v`.
   Pass: every return code 0, no landing sentence above 5 s.
   On failure: `git stash`-free recovery, restore the touched files from
   `HEAD` with `git show HEAD:<path> > <path>` and recompile them in the same
   order, so the tree's `.vo` files match its text again.
4. One commit for the library file, one for the instance and manifest files
   together (they do not compile apart), with the rows file.
5. As-built fidelity, by a rocq-prover subagent: `kim_asbuilt_fidelity.v` in
   the probe, importing the permanent modules. Pass: the probe fidelity
   file's counts, 62 within the three `boolp` axioms and 10 closed.
6. Rebuild the other probes' `.vo` files only when they are next used; their
   verification always recompiles from source in a fresh directory.
7. Record: closure section of the probe's `STATUS.md`, the spec's status line,
   the memory note, the summary note.
